# AaroGYM

An AI-powered fitness assistant that tracks workouts and gives personalized fitness recommendations. Built for a hackathon.

## Features

- Workout tracking
- AI-based fitness recommendations
- Progress visualization

## Tech Stack

- **Framework:** Next.js, React
- **UI:** Tailwind CSS, shadcn/ui (Radix primitives), Framer Motion
- **Forms & validation:** React Hook Form, Zod
- **Charts:** Recharts

## Getting Started

```bash
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) to view it.
